# Deep Agents Documentation

Welcome to the Deep Agents documentation.

## Courses

### [Build the Deep Agents CLI](course/index.md) 

A comprehensive 18-module course teaching how to build a production-quality AI coding CLI from scratch.

**What you'll build:** An interactive CLI with:
- Streaming AI responses
- Tool calling (file operations, shell commands)
- Human-in-the-loop approval gates
- Conversation history
- Skills and memory loading
- MCP tool integration
- Remote sandbox support
- Polished Textual TUI

**Duration:** ~40-60 hours (18 modules, 2-3 hours each)
